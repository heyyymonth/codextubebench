# Limitations

- The deterministic player uses a virtual timeline and authored metadata, not
  decoded audiovisual content.
- Fixture replay detects supported action-level disturbances but not every
  browser, extension, operating-system, or account side effect.
- The repository does not yet provide an automated provider runner for repeated
  Codex execution; current real-Codex capture is manual or semiautomatic.
- Browser/tool-call normalization varies by controller.
- Generic state-restoration scoring and automatic Codex failure-taxonomy
  assignment are partial.
- State tracking is planned. Channel selection, cost, and latency are partial.
- The ten `longform_seed` tasks are design contracts, not runnable fixtures.
- One local-fixture Codex run is protocol validation only.
- No live YouTube aggregate is currently approved or published.
- Live YouTube behavior depends on page availability, ads, consent,
  personalization, region, transcript coverage, UI experiments, network state,
  and browser configuration.
- Future live attempts must keep access modes separate and cannot establish
  GUI-native performance from instrumented runs.
- No account-mutating live tasks are authorized.
