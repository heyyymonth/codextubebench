# Limitations

- The deterministic player uses a virtual media timeline and authored metadata,
  not decoded audiovisual content.
- Fixture replay detects supported action-level disturbances but cannot observe
  every browser, extension, operating-system, or account side effect.
- The repository does not provide a provider-driven runner for repeated agent
  execution; current real-agent capture is manual or semiautomatic.
- Browser/tool-call normalization varies by controller. Generic restoration
  scoring, automatic failure labeling, state tracking, cost, and latency
  telemetry are incomplete.
- Retained TCE-002 traces establish protocol behavior, not task-complete
  deterministic benchmark performance.
- No live YouTube-only aggregate is currently approved or published.
- The 24-slot live-public pilot is a dated exploratory result, not a repeated
  benchmark score.
- The independent 72-attempt campaign covers one prompt, browser/model
  configuration, date, language regime, and limited public-site sample. Its
  within-campaign stability does not establish cross-agent or longitudinal
  reliability.
- Live page availability, ads, consent, personalization, region, transcript
  coverage, UI experiments, network state, and browser configuration can change
  the observable task surface.
- Live access modes remain separate; instrumented results do not establish
  GUI-native performance.
- Public live tasks are read-only and do not evaluate authenticated or
  consequential account actions.
