# Archived: Paper Strategy

This is a claim and section plan, not a manuscript.

## Candidate claims, conditional on results

1. Long-form YouTube exposes temporal observation-control failures that final
   task success does not capture.
2. Disturbance-free grounded success changes system rankings relative to exact
   success.
3. Successful agents can remain operationally poor because of excessive
   observation, insufficient evidence, or poor channel selection.
4. Transcript and instrumented access improve some tasks while creating
   modality-specific blind spots.
5. Explicit verification improves state safety and repeated-run reliability.
6. Controlled YouTube-like fixtures and live YouTube measure different
   generalization
   properties.

Do not freeze these claims before baseline and ablation results exist.
